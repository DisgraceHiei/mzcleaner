# C盘清理

> 基于 [mzcleaner/mzcleaner](https://github.com/mzcleaner/mzcleaner) 的 MIT 开源源码构建的免费版本。

原仓库以 MIT 协议开源，源码中并不包含任何授权验证或收费锁。本项目已移除品牌标识与引流入口，只保留纯粹的清理功能，开箱即用。

> 本项目与"磨针"品牌方无关。仓库名 `mzcleaner` 仅为保留上游链接有效性而沿用。

## 关于本项目

本项目由 **AI 辅助编写**（WorkBuddy）。界面设计、功能修复、清理规则与打包发布均由 AI 完成，人类负责提出需求与验证结果。所有源码公开可审查，遵循 MIT 协议。

## 与原版的区别

1. 移除了顶部导航栏中无实际功能的「VIP永久授权」「登录」占位按钮（原源码中这两个按钮没有绑定任何授权逻辑，登录弹窗输入后直接关闭）。
2. 修复了清理功能的一个 Bug：确认对话框的回调使用同步函数配合 `asyncio.ensure_future`，在 Flet 框架的事件循环中被调度到无事件循环的线程池，导致点击「确定清理」后清理任务未执行。现已改为 async 回调直接 `await`。
3. 修复了扫描进度回调中一处会产生 `RuntimeWarning` 的错误写法。
4. 修复了回收站清理会破坏系统回收站结构的问题：原版直接递归删除 `$Recycle.Bin` 目录，会删掉系统用于维护回收站的元数据文件（`desktop.ini`），导致 Windows 弹出"回收站损坏"。现改为调用 Windows 官方接口 `SHEmptyRecycleBinW`，只清空回收站内容、保留系统结构完整。
5. 新增「深度清理」：覆盖浏览器、开发工具、常用软件的缓存与系统日志、崩溃转储等。规则定义见 `clean_rules.py`，为本项目原创（MIT），参考了公开的工具缓存路径常识，未引入任何 GPL 授权的规则文件。规则仅纳入公认可安全清理的缓存/日志目录，不含文档、聊天记录正文、程序主体或系统关键组件。已覆盖：NVIDIA / DirectX 着色器缓存、剪映缓存、网易云音乐缓存、夸克浏览器缓存、崩溃转储、npm/pip 等开发缓存。
6. 新增「临时文件扫描」：按后缀（`.tmp/.bak/.dmp/.cache` 等）扫描散落的临时文件，实测约 600 MB。后缀清单属公开事实（开源清理工具通用），见 `temp_rules.py`（MIT 原创整理）。排除游戏缓存与依赖目录，避免误删。
7. 重新设计界面：深色分组式侧栏、靛蓝主色、圆形图标徽章、卡片化结果列表，与原界面在布局、配色与视觉语言上明显不同。
8. 新增「空间占用分析」：WizTree/SpaceSniffer 风格树状图，方块面积代表占用、显示名称与大小，按类别柔和配色，点击可下钻。纯只读，不提供清理（避免把程序本体当垃圾删除）。数值为估算值。

清理、扫描逻辑均来自原 MIT 源码，未作功能性改动（上述修复与新增除外）。

## 运行方式

需要 Python 3.10+（推荐 3.11/3.12）。

```bash
# 1. 安装依赖
pip install "flet>=0.28,<0.29"

# 2. 运行
python main.py
```

Windows 用户可直接双击 `run.bat`（会自动创建虚拟环境并安装依赖后启动，需已安装 Python 并加入 PATH）。

## 下载与杀毒误报

本项目提供两种预编译版本：

- **DiskCleaner.exe**（单文件，约 77 MB）：双击即用，但容易被 Windows Defender / 浏览器误报为病毒。
- **DiskCleaner-portable.zip**（约 13 MB）：解压后运行 `DiskCleaner\DiskCleaner.exe`，误报概率低得多，功能完全相同。

**为什么会被误报？** 项目用 PyInstaller 打包，单文件 exe 在运行时会自解压到临时目录再执行——这个行为模式与某些恶意软件相似，会触发杀毒软件的启发式检测。加上 exe 没有购买代码签名证书（每年数百至数千元，开源项目难以承担），Windows 也缺少它的安全声誉记录。**这是误报，不是真的有病毒**：全部源码都在本仓库，可自行审查或直接用 Python 运行。

**如果下载被拦截：**

1. Edge/Chrome 提示"检测到病毒"时，点「…」→「保留」→「仍要保留」即可下载；
2. 若被 Windows Defender 隔离，到「Windows 安全中心 → 病毒和威胁防护 → 保护历史记录」中找到该文件，选择「还原」，然后添加排除项；
3. 更省事的办法：直接下载 **portable.zip**，或按上面的方式从源码运行。

**帮我们消除误报**：可向微软提交误报申诉（https://www.microsoft.com/en-us/wdsi/filesubmission ），选择"文件不应被检测"，附上本仓库源码链接。提交的人多了，误报就会消失。

## 使用步骤

1. 启动后，在左侧选择一个清理类别（如「基础清理」）。
2. 点击「开始扫描」，等待扫描完成。
3. 扫描出结果后「开始清理」按钮才会变为可用。
4. 点击「开始清理」→ 在确认框中点「确定清理」。

## 功能

- 基础清理：临时文件、回收站、浏览器缓存等
- 系统清理：系统更新缓存、日志等
- **深度清理：浏览器 / 开发工具 / 常用软件缓存、系统日志、崩溃转储（新增）**
- **临时文件扫描：按后缀找散落的 .tmp/.bak/.dmp（新增）**
- 微信 / QQ 缓存清理
- 大文件、重复文件、相似文件查找
- 目录大小分析、软件占用查询
- 用户目录迁移、软件搬家（高级功能，操作前请自行确认风险）

> 提示：清理操作不可撤销。程序遵循"宁可少删、不误删"原则，但涉及系统目录和迁移类操作前仍建议先备份重要数据。

### 空间分析会显示、但清理不会删除的项目

「空间占用分析」的树状图会**列出**下面这些目录的大小（目的只是帮你定位空间被谁占用），但**清理功能不会删除它们**：

- **Windows 系统目录**：包括 `WinSxS` 组件库。系统清理只处理其中明确安全的子项（如 `WinSxS\ManifestCache` 清单缓存），并调用系统自带接口；整个 WinSxS 本体不动，要缩减只能用系统 DISM 命令。
- **Program Files / Program Files (x86)**：已安装程序本体，删除会导致软件无法运行——仅在树状图中显示占用。
- **游戏预编译着色器**（如 XboxGames\Shaders）：删除后首次进游戏要重新编译、造成卡顿，属于"代价大于收益"。注意这与"显卡驱动着色器缓存"（`NVIDIA\DXCache`，会自动重建、可清理）是两回事。
- **Downloads 等个人目录**：你的文件，工具不碰，仅在树状图中显示大小，去留请自行决定。
